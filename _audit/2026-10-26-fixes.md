## 1. N 47 -- several controls bound to the Page's one heading are one control

**MEASURED GROUND.** The session-10 record recovered the refusal off the shipped
verdict, driving `writes.company_page_follow_verdict` over a grid of readings:

> "exactly one sentence matches: 2 controls whose name opens `Follow ` in the
> Page's main column, and 2 of them read it followed by a heading the Page prints
> there -- refused as several bound. So unfollowed, the Page draws its OWN
> control twice in the main column, both named for it (DERIVED from the
> sentence: two controls bound to the Page's own heading)."

**THE DEFECT.** `dom.read_company_page_follow` counted `bound_controls`, and the
verdict admitted several main-column controls only when exactly ONE was bound.
Two copies of the Page's own control read 2, so the gate refused the one Page it
was asked to follow.

**THE FIX** (`linkedin_server/dom.py`, `linkedin_server/writes.py`):

* the reader reports `bound_headings` -- how many DISTINCT headings the bound
  controls name -- and sets the subject when they all name one;
* the verdict admits several bound controls when `bound_headings == 1`; bound
  controls naming DIFFERENT headings still refuse, as picking by position;
* the page engine's exact count of bound controls must EQUAL this server's
  whitespace-folded count (it used to be required to equal 1);
* the press is a new constant, `dom.COMPANY_PAGE_TOPCARD_FOLLOW_CONTROL`, which
  the verdict requires to match exactly one element: the bound control that is
  alone among bound controls in its nearest heading-holding ancestor -- the
  Page's top card. No position, no "first match", nothing the page wrote
  spliced into the selector.

**THE AIM, MEASURED OFFLINE (2026-11-24).** `COMPANY_PAGE_TOPCARD_FOLLOW_CONTROL`
counted over the committed fixture's worlds and over the raw Page-root capture
held outside the tree (`_state/cap-company-root.html`, gitignored; an
organisation's page, so only counts were taken):

| a second control bound to a DIFFERENT heading | 2 | 2 | refuses |
