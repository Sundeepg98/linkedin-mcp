### 1.2 The guard reads the row's own claim

`tests/test_the_census_prose_matches_the_boundary.py` gained a reader for the claim, taken from the same
row's MEASURED cell through the existing `_reachable_row` (the census's own cell reader). It reads the
backticked substrings, the match count stated for each, and the pattern count. All three are held to
`readonly._ALLOWED_URL_PATTERNS`. A substring matches a pattern when it occurs in the pattern's source,
case folded. That is the stricter reading, because it finds everything the exact one finds. The 2026-09-20
record states the zeros but not the code that produced them (its section 6.1 lists the count, the
`is_read_url` calls and the sanctioned kinds only), so this definition is stated here and in the module.

Four new tests:

| test | holds |
|---|---|
| `test_the_reachable_rows_claim_is_readable` | control: the claim is found, with at least one substring, or it fails loudly |
| `test_the_reachable_rows_pattern_count_is_the_boundarys` | the stated count is `len(readonly._ALLOWED_URL_PATTERNS)` |
| `test_each_substring_the_reachable_row_names_matches_as_it_says` | each substring matches exactly the stated count of pattern sources |
| `test_the_reachable_rows_claim_reader_can_fail` | shown failing twice: one pattern too many, then `linkedin` (which all 109 sources carry) are each read as a disagreement |
