## 12. Lessons

1. **A reader keyed on a table's column words reads whichever table it meets.** LinkedIn writes the
   same header words on its headcount table and its job-openings table. Only each table's own
   `summary` says which one it is. The shipped reader returned openings as employee counts on one
   capture and read nothing on the next. Key a data table on its own label, and test it on a page
   that draws BOTH tables (section 11.6; INSTRUMENTS 114.5).
2. **A keyed-shape search for a word must try its case.** The headcount table's first header was
   `total employees`, in lower case. 46 capitalised spellings matched nothing, and the first case
   variant matched. When a shape's letter, digit and length counts fit a known phrase, try its case
   variants before widening the phrase list (section 11.7).
3. **`lane_ci.py push` refuses a dirty tree, so CI only runs on a clean one.** This lane began the
   next commit's edits while commit 5's push was queued behind its gates. The push was refused, no
   run started, and the wait task polled for a run that would never exist until it was stopped.
   Push, see `push exit 0`, and only then edit (section 10).
4. **The reader-inventory writer re-measures every reader, not only the new one.** On this box it
   recorded four navigating server readers as `timed out after 5.0s`, where the committed baseline
   says `navigates (page.goto)`. It did so on three runs, contended or quiet. Those verdicts come
   from the environment, not the change. Keep the committed file as it is and add only the readers
   that are absent from it.
5. **Cite a lane's own commits by ordinal, never in a `commit <sha>` slot.** A lane SHA is not on
   master until integration. The cited-SHA guard ancestry-checks every commit slot against master,
   so the lane CI went red on this record's own sentence (run 45967130401).
6. **Backticks inside a double-quoted `python -c "..."` are shell command substitution.** One such
   command tried to run census words and a fixture as programs; nothing was written, because its
   own assertion then failed. Pass markdown only through a script file
   (`dont-write-code-with-escapes-through-a-heredoc`, again).
7. **A helper that takes the reader's output dict cannot be driven by the leak harness.** The
   harness supplies `{}`. `_read_alumni(page, out, failed)` was recorded
   `not_driven:raises KeyError`. As `_read_alumni(page, failed)`, returning its own reading, it is
   driven and recorded `returns_records`. Give a page helper only the page and its counters.
8. **A guard keyed on a bare word fires on a different field carrying the word.** The proximity
   guard keeps the job card's "company alum works here" line in `shape.py` alone, by matching
   `alum`. The Insights tab's "Notable company alumni" module reddened it on lane CI (run
   45977558813). The fix declares the second field, bounded to its section and barred from the
   proximity line's own words, with a control. It does not rename the code to dodge the word,
   which would have left the guard blind to the next real spread.
