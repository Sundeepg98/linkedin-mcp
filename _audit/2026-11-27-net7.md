## Lessons (for the orchestrator to harvest)

1. A CLOSED VOCABULARY YOU WRITE BY HAND MISSES THE WORD THE PAGE USES; THE
   REPOSITORY'S OWN TEXT IS A BETTER ONE. 13,072 hand-built type-pill spellings
   and 625,080 two-word candidates matched one of the received tab's three
   pills; every seven-letter word in the repository's tracked text (4,987
   words) named the third, `Focused 3`, in one run. Each candidate is still a
   closed string hashed and compared, and only exact matches print.
2. A LINK A PANEL DRAWS IS NOT ITS STATE. The first-degree panel drew `1st`
   checked and a `Show results` link with no `network`. A capture that reads
   such a link after a press can prove a key present, never absent.
3. A LATER SENTENCE IN A RECORD CAN CONTRADICT AN EARLIER TABLE IN THE SAME
   RECORD. Lane S's `N 26b` split ("on record nowhere here") sat four days
   after its own section 2 table recording both spellings. Re-measure the
   table's source before quoting either.
4. ON A SHARED BOX, A RUN THAT PRINTS NOTHING IS STILL RUNNING UNTIL THE
   PROCESS LIST SAYS IT IS NOT. A census batch of 19 files hit its 400 s
   timeout while four other lanes' suites ran, and a second half started by
   the same command overlapped a rerun this lane launched on a silent output
   file: two identical pytest processes, found by `Win32_Process` with their
   start times, one stopped by its verified PID. Measure before relaunching.
5. A CHECK AND THE ACT IT GUARDS, IN ONE COMMAND, IS NO CHECK. This lane's
   boundary check for an order on disk ran in the same shell command as the
   commit it guarded; the order was found and printed, and the commit went
   ahead before it was read (`0423e6b`). Nothing in that commit contradicted
   the order. Run the check, read its output, then act.
